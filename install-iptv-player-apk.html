How to install StreamX on Android TV (APK)

Install the StreamX media player on Android TV, Google TV, Chromecast with Google TV, Nvidia Shield or Fire TV in a few minutes. Download the APK, copy it to your TV, and open it.

StreamX is a media player only. It does not provide any channels, movies, series or streams. You add a playlist, portal or login that you already have the right to use.

Before you start

  • Your device must run Android 6.0 (API 23) or newer.
  • Always download the file from the official Releases page. Do not install copies from other sites, because a modified file can be unsafe.
  • The file is named like StreamX-1.0.0.apk.

Method 1: a USB stick

  1. Download the APK on a computer and copy it to a USB stick.
  2. Plug the stick into the TV and open a file manager app on the TV.
  3. Open the APK. If asked, allow Install unknown apps for the file manager.
  4. Choose Install, then Open.

Method 2: the Downloader app (Android TV, Google TV and Fire TV)

  1. Install a file-downloader app on the TV and allow it to install unknown apps in the TV settings.
  2. Open the app and enter the address of the Releases page, or download the APK on your phone and share it to the TV.
  3. Download the APK, then choose Install.

Method 3: adb over the network

  1. On the TV, enable Developer options and Network debugging (or ADB debugging).
  2. On a computer on the same network, run adb connect TV-IP-ADDRESS:5555.
  3. Run adb install StreamX-1.0.0.apk.

After installing

Open StreamX, then Profile → Manage Sources to add an M3U playlist, an Xtream Codes login or a Stalker / MAG portal. StreamX includes no channels, so you add your own source.

Troubleshooting

  • "App not installed": the Google Play build and the sideloaded APK are signed with different keys. If you installed one, uninstall it before installing the other.
  • "Install blocked": allow Install unknown apps for the app you used to open the file.
  • The APK does not open: check that the download finished and that the TV runs Android 6.0 or newer.

Frequently asked questions

Is the StreamX APK safe to install?

Download it only from the official Releases page. The APK is signed by the developer, and StreamX is a player that includes no content.

Can I install it on Fire TV?

Yes. Fire TV runs Android and can install the APK with a downloader app or adb, as long as it runs Android 6.0 or newer.

Will the Google Play version replace the APK?

Not directly. The two are signed with different keys, so uninstall one before installing the other.
